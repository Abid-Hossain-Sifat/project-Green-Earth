#  🌱 Green Earth Project

A modern platform for planting trees and promoting environmental sustainability.

---

## 📌 Description

Green Earth Project is a clean and responsive web platform built with HTML, CSS, Tailwind CSS, and JavaScript. It allows users to explore different types of trees, view environmental impact, and contribute to a greener planet through tree planting.

With a focus on simplicity, performance, and user-friendly design, the platform delivers a smooth experience for users to browse, select, and support eco-friendly initiatives.

---


## 🛠️ Technology

- 🌐 HTML5  
- 🎨 CSS3 + Tailwind CSS + Daisy UI 
- 🧠 JavaScript (ES6+)  
- 🔗 API Integration 
- 📦 JSON 

---



## ✨ Features
### 🌳 Tree Selection System
- Browse different categories of trees
- View tree details with images and pricing
- Add trees to cart easily

### 🛒 Smart Cart Functionality
- Add-to-cart system with real-time updates
- Displays total price dynamically
- Prevents duplicate selections
### 🔍 Category Filtering
- Filter trees by type (Fruit, Flowering, Medicinal, etc.)
- Improves user navigation and experience
### 📊 Impact Showcase
- Displays total trees planted
- Shows global reach and community involvement
- Builds trust and awareness
### 🌍 Campaign Information Section
- Highlights environmental mission
- Educates users about climate impact
- Encourages participation
### 📩 Donation / Plant Form
- Simple and clean form UI
- Users can submit details to plant trees
- Smooth interaction with clear CTA

# 🚀 Run Locally

### Follow these steps to run the Green Earth Project on your local machine:

### 📌 Prerequisites
- 💻 A code editor like VS Code (optional, but recommended)
- 🌐 Any modern browser (Chrome, Edge, Firefox, etc.)
- 📥 1. Clone or Download the Project
```js
git clone https://github.com/Abid-Hossain-Sifat/project-Green-Earth.git
cd project-Green-Earth
```

Or download the ZIP file and extract it.

# ▶️ 2. Open in Browser

### Since this is a pure HTML/CSS/JS project, you can run it directly:

- Open the index.html file in your favorite browser
- Or use VS Code Live Server extension for automatic refresh:
- Install Live Server in VS Code
- Right-click index.html → Open with Live Server
- Browser will open at something like http://127.0.0.1:5500
# ✅ 3. Explore and Modify

### Now you can:

Browse tree categories
Test the cart and form functionalities
Modify HTML, CSS, or JS locally and see changes instantly (with Live Server)
